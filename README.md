# Классические процедуры голосования

## Процедура Борда

Каждый участник ранжирует все альтернативы по предпочтительности.

Если имеется `m` альтернатив:

- 1 место получает `m-1` баллов  
- 2 место получает `m-2`  
- ...  
- последнее место получает `0`

Для альтернативы $a_i$ определяется значение:

$$
r_s(a_i) = \text{число альтернатив, стоящих ниже } a_i
$$

Функция Борда:

$$
F_B(a_i) = \sum_{s=1}^{t} b_s(a_i)
$$

Победителем является альтернатива:

$$
a^* = \arg\max_i F_B(a_i)
$$

---

## Процедура Симпсона

Для каждой альтернативы определяется минимальное число голосов, полученных в попарных сравнениях.

Функция Симпсона:

$$
F_S(a_i) = \min_{j \ne i} g(a_i,a_j)
$$

где  

$g(a_i,a_j)$ — число избирателей, предпочитающих $a_i$ альтернативе $a_j$.

Победитель:

$$
a^* = \arg\max_i F_S(a_i)
$$

---

## Процедура Доджсона

Процедура Доджсона оценивает **минимальное число изменений в ранжировках**, необходимое для того, чтобы альтернатива стала победителем по правилу Кондорсе.

Вводится значение:

$$
g_{1/2} =
\begin{cases}
t/2, & \text{если } t \text{ четно} \\
(t+1)/2, & \text{если } t \text{ нечетно}
\end{cases}
$$

Функция Доджсона:

$$
F_D(a_i) = \sum_{j \ne i} \max(g_{1/2} - g(a_i,a_j))
$$

Победителем является альтернатива:

$$
a^* = \arg\min_i F_D(a_i)
$$

# Комбинированная процедура

Метод объединяет три классические процедуры.

Пусть:

- $A = \{A_1, ..., A_m\}$ — множество альтернатив  
- $S = \{1,...,t\}$ — множество избирателей  

---

## Шаг 1. Построение матрицы попарных сравнений

Строится матрица

$$
G = (g_{ij})
$$

где

$$
g_{ij} = |\{ s \in S : A_i \succ A_j \}|
$$

---

## Шаг 2. Критерий Борда

$$
f_B(A_i) = \sum_{j \ne i} g_{ij}
$$

Он отражает **суммарную силу предпочтений**.

---

## Шаг 3. Минимальная поддержка (Симпсон)

$$
s_i = \min_{j \ne i} g_{ij}
$$

Этот показатель характеризует **устойчивость альтернативы к наихудшему оппоненту**.

---

## Шаг 4. Дефицит большинства (Доджсон)

Вводится порог

$$
q = \frac{t}{2} + 1
$$

Дефицит:

$$
d_i = \sum_{g_{ij} < q} (q - g_{ij})
$$

---

## Шаг 5. Итоговая функция

Итоговая оценка альтернативы:

$$
F(A_i) = \alpha f_B(A_i) + \beta s_i - \gamma d_i
$$

где

$$
\alpha + \beta + \gamma = 1, \quad \alpha,\beta,\gamma \ge 0
$$

Победитель:

$$
A^* = \arg\max_i F(A_i)
$$

---

## Анализ устойчивости

Для анализа устойчивости выполняется перебор весов:

α ∈ [0,1]

β ∈ [0,1−α]

γ = 1 − α − β


Для каждой комбинации:

1. вычисляется $F(A_i)$  
2. определяется победитель  
3. подсчитывается статистика побед  

Это позволяет оценить **чувствительность результатов** к изменению приоритетов критериев.

## Формат входных данных

Входные данные задаются в формате JSON:

```json
{
  "metadata": {
    "title": "Example",
    "source": "Textbook"
  },
  "alternatives": ["A", "B", "C"],
  "rankings": [
    {
      "order": ["A", "B", "C"],
      "voters": 23,
      "weights": {"A": 2, "B": 4, "C": 5}
    },
    {
      "order": ["B", "C", "A"],
      "voters": 17,
      "weights": {"A": 6, "B": 1, "C": 3}
    }
  ],
  "utilityProfiles": [
    {
      "id": "Expert-1",
      "weight": 0.5,
      "utilities": {"A": 0.90, "B": 0.70, "C": 0.40}
    }
  ]
}
```

### Описание полей

- `alternatives` — массив имён альтернатив.
- `rankings` — массив ранжировок:
  - `order` — упорядочение альтернатив (первый элемент — лучший);
  - `voters` — число голосов за данную ранжировку;
  - `weights` — (опционально) веса мест для взвешенной суммы.
- `utilityProfiles` — (опционально) массив экспертов для метода Харшаньи:
  - `id` — идентификатор эксперта;
  - `weight` — вес эксперта;
  - `utilities` — значения полезности для каждой альтернативы (от 0 до 1).
